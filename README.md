# Airport Traffic Analysis

Я исследовал пассажиропоток аэропортов: обработал годовые таблицы, подготовил статистические сравнения и визуализацию в Jupyter.

## Запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook
```

## Устройство проекта

Основные ноутбуки: `airport_eda_project.ipynb` и `analiz.ipynb`. CSV-таблицы 2019–2022 годов предоставляются отдельно; ожидаемые имена указаны в коде. Выводы ноутбуков очищены.

Я публикую исходный код без локальных паролей, окружений, баз и журналов. Для воспроизведения анализа я указываю необходимые данные и зависимости.
